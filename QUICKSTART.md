# Quick Start Guide - Stock Prediction Dashboard

Get the full-stack application running in minutes!

## Prerequisites

- **Python 3.9+** (check: `python --version`)
- **Node.js 18+** (check: `node --version`)
- **FRED API Key** (get free at https://fred.stlouisfed.org/docs/api/api_key.html)

## Step 1: Set Environment Variables

### Windows (PowerShell)
```powershell
$env:FRED_API_KEY="your_fred_api_key_here"
```

### Linux/Mac
```bash
export FRED_API_KEY="your_fred_api_key_here"
```

Or create a `.env` file:
```
FRED_API_KEY=your_key_here
```

## Step 2: Backend Setup

```powershell
# Navigate to backend
cd backend

# Create virtual environment
python -m venv venv

# Activate virtual environment
# Windows:
.\venv\Scripts\activate
# Linux/Mac:
# source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Start backend server (in one terminal)
uvicorn app.main:app --reload --port 8000
```

Backend will be available at: **http://localhost:8000**

API Documentation: **http://localhost:8000/docs**

## Step 3: Generate Initial Data (Dummy Mode)

Open a **new terminal** (keep backend running):

```powershell
cd backend
.\venv\Scripts\activate  # Activate venv again

# Generate dummy predictions for testing
python scripts/predict.py --dummy
```

This creates sample predictions in the database without requiring a trained model.

## Step 4: Frontend Setup

Open a **new terminal**:

```powershell
# Navigate to frontend
cd frontend

# Install dependencies
npm install

# Start development server
npm run dev
```

Frontend will be available at: **http://localhost:3000**

## Step 5: Explore the Dashboard

1. **Main Dashboard** (http://localhost:3000)
   - View all stock predictions
   - Filter by horizon (1/5/20 days)
   - Search for specific tickers
   - Toggle live updates

2. **Ticker Details** (click any ticker)
   - Detailed prediction view
   - Probability charts over time
   - Expected return trends
   - Historical predictions table

3. **System Health** (http://localhost:3000/health)
   - Backend status
   - Database connectivity
   - Model version info

## Testing Live Updates (SSE)

1. On the main dashboard, click **"Connect Live"**
2. The indicator will turn green 🟢
3. Predictions update automatically every 2 seconds
4. Run `python scripts/predict.py --dummy` again to see live updates

## API Endpoints

### Health & Info
- `GET /health` - System health check
- `GET /api/tickers` - List available tickers

### Predictions
- `GET /api/predictions/overview?horizon=5&limit=200` - Overview of all predictions
- `GET /api/predictions/latest?ticker=AAPL&horizon=5` - Latest prediction for ticker
- `GET /api/predictions/history?ticker=AAPL&horizon=5&limit=500` - Historical predictions

### Streaming
- `GET /api/stream?horizon=5` - Real-time SSE stream

## Common Issues

### Backend won't start
```
Error: no module named 'fastapi'
Solution: Make sure you activated the venv and ran pip install -r requirements.txt
```

### Database is empty
```
Solution: Run: python backend/scripts/predict.py --dummy
```

### Frontend can't connect to backend
```
Error: Failed to fetch
Solution: 
1. Make sure backend is running on port 8000
2. Check http://localhost:8000/health in browser
3. Verify CORS is enabled in backend/app/main.py
```

### FRED API key error
```
Error: FRED_API_KEY not found
Solution: Set environment variable before running scripts
```

### Live updates not working
```
Solution:
1. Check browser console for EventSource errors
2. Make sure backend /api/stream endpoint is accessible
3. Try disabling browser extensions that block SSE
```

## Next Steps

### Train Real Model (TASK 13)

Once you're ready to train a real model:

1. **Set up notebook environment**
   ```powershell
   cd notebooks
   pip install -r requirements.txt
   jupyter notebook train.ipynb
   ```

2. **Run all cells** in the notebook (currently has placeholders)
   - Fetches real stock data from yfinance
   - Downloads macro indicators from FRED
   - Engineers features with technical indicators
   - Trains XGBoost classifier
   - Exports artifacts to `artifacts/` directory

3. **Generate real predictions**
   ```powershell
   cd backend
   python scripts/predict.py  # No --dummy flag
   ```

4. **Predictions now use trained model** instead of dummy data
